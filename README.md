# 工银金融时空局

## 这是什么？

“工银金融时空局”是一款手机端互动 H5。你将以“见习财富调查员”的身份，进入历史档案，调查贾府面临的现金流问题，并通过查账和决策理解金融知识。

## 如何使用

这是一个网页应用，不需要安装软件。使用手机浏览器打开项目发布后的网页地址即可开始体验。建议竖屏打开，并在首次进入时等待页面加载完成。

## 操作流程

1. 在启动页点击“启动时空档案”。
2. 在管理局大厅完成身份确认和任务说明。
3. 选择《贾府现金流危机》档案。
4. 在账房页面依次查看账本、核对到款、询问账房。
5. 阅读线索，判断现银紧张的主要原因。
6. 提交周转方案，查看短期支付能力和资金周转风险的变化。
7. 点击“进入复盘”，阅读本阶段金融逻辑。
8. 复盘结束后可以返回管理局大厅。

## 三份历史档案

- **贾府现金流危机**：当前开放体验的主线档案。
- **鲁滨逊岛资本实验**：暂时封存。
- **百万英镑信用迷局**：后续开放。

## 体验提示

- 页面按照手机竖屏设计，建议不要横屏使用。
- 贾府页面中的账本、到款和账房都可以点击查看。
- 需要先收集完线索，才能进入后续判断。
- 页面中的人物、金额和事件用于教学演示，均为虚构内容。
- 本项目不连接真实银行账户，也不会收集个人信息。

## 如果页面打不开

请确认打开的是 GitHub Pages 发布地址，而不是电脑本地地址 `127.0.0.1`。仍未显示时，可以刷新页面，或换用手机系统浏览器再次打开。

本项目为比赛概念原型，打开网页即可使用，不需要安装、登录或输入任何个人信息。
