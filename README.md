# 工银金融时空局

一款面向手机竖屏设计的历史金融互动 H5。无需下载或安装，打开网页即可体验。

你将以“见习财富调查员”的身份进入历史档案，通过查看账本、核对到款、询问人物和制定资金周转方案，调查财富系统失衡的原因。

目前可完整体验主线档案《贾府现金流危机》，另外两份档案将在管理局大厅中以信号碎片的形式出现。

## 在线体验

请使用手机浏览器竖屏打开：

https://www-11111.github.io/jrskj/

建议使用手机系统浏览器。首次进入时，请等待图片和页面资源加载完成。

## 使用说明

1. 打开在线体验地址。
2. 保持手机竖屏。
3. 点击启动页画面下方按钮进入。
4. 跟随页面提示完成身份确认和任务说明。
5. 进入贾府档案，调查现金流异常。
6. 全程通过点按操作，无需登录，也不需要填写个人信息。

## 当前主线：贾府现金流危机

贾府账面资产充裕，但可用现银持续减少：

- 账面资产：12400 两
- 当前库银：380 两
- 10 天内刚性支出：2200 两（节礼 1200 两 + 修缮 1000 两）
- 应收款：5000 两，预计晚到 20 天
- 未入账旧借：800 两

你的任务是查清问题，并制定短期资金周转方案。

## 完整体验流程

1. 启动时空档案

点击启动页中的“启动时空档案”，进入序章并检索异常档案信号。

2. 抵达管理局大厅

按照顺序完成：

- 身份确认
- 任务说明
- 锁定《贾府现金流危机》

3. 进入贾府调查

在第一幕中依次完成三项调查：

- 查看账本
- 核对到款
- 询问账房

集齐 3/3 条线索后，才能进行初步判断。

4. 判断异常原因

根据已获得的线索选择怀疑方向。

此时系统只记录你的判断，不会立即公布对错。

5. 制定周转方案

在第二幕中选择一种处置方式：

- 优先催收应收款
- 延后非必要支出

不同的怀疑方向与处置方案组合，会产生不同结果。

6. 查看阶段结果

提交方案后，可以查看：

- 库银还能支撑多少天
- 当前资金缺口
- 暗借状态
- 短期支付能力变化
- 资金周转风险变化

7. 进入复盘

复盘页将说明本案涉及的金融逻辑，并展示三笔资金之间的对应关系。

完成复盘后，可以返回管理局大厅。

8. 查看归档与新信号

通关后，《贾府现金流危机》会变为已归档状态，同时可以查看另外两份档案的新信号。

你也可以重新体验主线，选择不同判断与方案，对比不同结局。

账面资产并不等于随时可用的现金。玩家需要识别应收款延迟、刚性支出和未入账借款之间的关系，理解现金流与短期支付能力。

大厅预告档案。

## 体验提示

- 页面按手机竖屏设计，请勿横屏使用。
- 第一幕必须集齐三条线索，才能继续判断。
- 如果在微信内打开时图片模糊或文字过小，可以点击右上角，选择“在浏览器中打开”。

## 页面打不开怎么办

请依次尝试：

1. 确认打开的是线上 Pages 地址，而不是 127.0.0.1 本地地址。
2. 刷新页面并等待资源重新加载。
3. 使用手机系统浏览器重新打开。
4. 在地址后添加随机参数，强制加载最新版本，例如：

https://www-11111.github.io/jrskj/?t=1
