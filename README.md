# 工银金融时空局

> 一个可以直接在手机浏览器打开的互动式金融教育 H5 原型。

## 给读者：怎么玩

打开网页后，请按下面顺序体验：

1. 点击“启动时空档案”，进入时空档案系统。
2. 在管理局大厅完成身份确认和任务说明。
3. 打开《贾府现金流危机》档案，进入账房。
4. 依次点击“查看账本”“核对到款”“询问账房”，收集三条线索。
5. 根据线索选择你认为最主要的现金流问题。
6. 提交周转方案，查看阶段结果，再进入复盘页。
7. 在复盘页阅读金融逻辑，也可以返回管理局。

本 H5 是教学演示，不需要登录、不收集个人信息，也不会连接真实银行账户。页面中的人物、金额和结局均为虚构的案例设定。

一个面向手机端的互动式金融教育 H5 概念原型。

用户以“见习财富调查员”的身份进入时空档案系统，调查历史世界中的财富失衡问题。当前首个可玩档案为《贾府现金流危机》，通过查账、线索判断和周转方案，让用户理解“账面资产”和“可用现银”之间的区别。

## 项目定位

本项目是一套适合比赛演示的短流程互动 H5：未来机构负责承载系统入口和档案管理，历史场景负责呈现具体金融问题，用户通过有限线索完成判断，系统用阶段结果和复盘解释金融逻辑。

整体视觉遵循两套明确风格：

- 时空局与管理大厅：深海军蓝、冰青、少量冷光；
- 贾府档案：砖红、深木色、暖纸色。

## 当前体验流程

1. 启动页：显示“工银金融 / 时空局”、世界观副标题和启动按钮。
2. 穿越序章：展示系统唤醒、历史档案检索和未知异常信号。
3. 管理局大厅：完成身份确认和任务说明，再查看三份历史档案。
4. 贾府第一幕：查看账本、核对到款、询问账房三条线索。
5. 第二幕：选择周转方案，查看短期支付能力和资金周转风险变化。
6. 阶段复盘：解释账面资产、可用现银、到账时间和支出时间之间的关系，并返回管理局。

管理局档案状态如下：

- 贾府现金流危机：可进入；
- 鲁滨逊岛资本实验：档案封存；
- 百万英镑信用迷局：待解锁。

## 本地运行

如果电脑已安装 Node.js 18 或更高版本，可以在项目目录运行：

    node serve.mjs

本机访问地址：

    http://127.0.0.1:4173

同一 Wi-Fi 下的手机访问，需要使用电脑的局域网 IPv4 地址，例如：

    http://192.168.1.23:4173

电脑防火墙需要允许 4173 端口。

## GitHub Pages 部署

本项目是纯静态 H5，不需要数据库或后端服务。

1. 将本目录下的全部内容上传到 GitHub 仓库根目录；
2. 打开仓库的 Settings；
3. 进入 Pages；
4. 在 Build and deployment 中选择 Deploy from a branch；
5. 选择 Branch：main，Folder：/ (root)；
6. 保存并等待 GitHub 完成部署。

仓库名为 jrskj、用户名为 www-11111 时，公开地址通常为：

    https://www-11111.github.io/jrskj/

首次部署可能需要等待几分钟。手机访问时应使用完整的 HTTPS 地址，不要使用 127.0.0.1。

## 设计与交互约束

- 以 390×844 手机画布为设计基准；
- 管理局使用未来机构视觉，贾府打开后才进入古风暖色；
- 每个页面只出现一个工小智；
- 不在静态启动页提前放钱币；
- 序章中的异常先保持悬念，大厅再解释贾府现金流问题；
- 贾府内部点击线索时不播放整页闪烁；
- 只在进入贾府时播放一次暖色转场；
- 不加入未讨论的复杂仪表盘、无意义数据面板或满屏霓虹装饰。
